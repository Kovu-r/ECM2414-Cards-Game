# ECM2414-Cards-Game


### A multi threaded card game built for java

## prerequisites

Built with Java version LTS at the time of this document being written, JDK version 25.

## How to compile
To compile the software, open this repository in any IDE supporting java version 25, and run SourceCode/Game/CardGame.java
This is the game's entrypoint.

## How to test the program
JUnit 4 has been used to test the program.
Open Compiled/Tests and run the test classes directly. An IDE can be used to run individual method tests if needed.
